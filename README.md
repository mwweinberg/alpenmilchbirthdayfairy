# Alpenmilch Birthday Fairy

Single-page Eleventy site.

## Setup

    npm install
    npm start        # dev server at http://localhost:8080
    npm run build    # outputs to _site/

## Hero image

The page expects `src/img/cosumes.png`. Drop the file there and it will appear as the hero.

## Editing content

- Intro text: `src/index.njk`
- FAQ entries: `src/_data/faq.json` (answers accept HTML)
